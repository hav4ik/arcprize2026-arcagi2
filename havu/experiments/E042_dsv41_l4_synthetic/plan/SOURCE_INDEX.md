# Sources and provenance

Prepared 20 October 2026. Exact source pins are used for implementation findings; live overview/recipe pages are dated context, not immutable locks. Repository source inspection and CPU arithmetic are distinct from GPU validation.

## Model and hardware

- **M1 — Exact 1017 configuration:** [DeepSeek-V4.1-Flash-1017 config at revision 1bae0e1088993b9b82de08f59de5be5a34e42170](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017/blob/1bae0e1088993b9b82de08f59de5be5a34e42170/config.json). The exact 3,311-byte response is bundled as metadata/source_config.json. SHA256: `8be45ce0476004a3f529fd896115a4a2e800a129ad2d3ec05b16050f52e21879`. Architecture, counts, original hash dimensions and quantization fields come from this file. Model license is included as metadata/SOURCE_MODEL_LICENSE (1,084 bytes; SHA256 `f2c6c602815669d292889e5be8c802f2ed950653b77999b1584e8e6aed25d040`).
- **H1 — L4 specifications:** [NVIDIA L4](https://www.nvidia.com/en-us/data-center/l4/), consulted 20 October 2026: advertised 24 GB, 300 GB/s and PCIe Gen4 x16. Usable memory, clocks, topology and provider limits still require inventory.
- **H2 — GPU architecture:** [NVIDIA CUDA GPU compute capabilities](https://developer.nvidia.com/cuda-gpus), L4/SM89 reference. Device execution and inventory are the acceptance evidence.

Lists SM100/Ascend 950, offline inference and additional service components; published scale differs from four L4s. Its ideas are a reference, not the initial SM89 implementation plan.

Recheck actual equivalent L4 support before an engine comparison; no current recipe establishes this exact E64/compact-Engram/L4 combination.

## User-supplied plan and calculations

The original uploaded **deepseek_v41_arc_agi2_agent_pack(1).zip** supplies the E64/E72 objective, tool-free ARC target, frozen-Engram-before-REAP sequence and provisional 12.6 GiB fixed-weight allowance. This package keeps those choices and changes the first inference session to synthetic weights on the user's first 4×L4 rental.

The unchanged tools/estimate_budget.py and tools/probe_environment.py were copied from that pack. Exact estimator commands and hashes are retained in verification/budget_scenarios.json. Host RAM/disk recommendations, session time caps, 8/32 GiB synthetic table scenarios and the adaptive test sequence are engineering recommendations, not published benchmark results.
