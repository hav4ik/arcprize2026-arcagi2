# dsv41 Kaggle solver: fixes required before the next candidate

Open gaps in the code of `dsv41-tools-submit-mtf` Version 6 (solver 4b344011, harness a8a5b665; copies in
`pinned_mtf_v6/`), found by the adversarial reviews of 2026-10-26. None cost a point in any recorded run, so V6 was
submitted as is on 2026-10-26 (no rebuild). **The next candidate must close every item below, each with a regression test**, then pass the
usual gates (unit tests, fake-server dry run in rerun mode, pod stress test, Kaggle smoke) before submission.

Status: `open` until the fix and its test are merged; then `fixed (<commit or sha>)`.
