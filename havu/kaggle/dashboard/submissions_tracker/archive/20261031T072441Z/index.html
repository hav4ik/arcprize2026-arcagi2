Throughput over time

10-minute means of per-minute server metrics (0 while the server hangs or restarts), by hours since the solver started. Shaded bands mark outages. The B32 reference's swings are real: the KV gate admits a batch, contexts grow until KV is full and requests get preempted, attempts finish, and the gate admits again. Once the KV cache is ~85% full, the solver admits no new attempts, so fewer requests run and total tokens/s falls while each stream gets faster.
