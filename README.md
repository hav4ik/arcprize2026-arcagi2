# arcprize2026-arcagi2
## Layout: one folder per contributor
Each contributor works in their own top-level folder (e.g. `havu/`), so everyone can explore ideas freely without
changing other people's code, while still being able to read and reuse it. To build on someone else's work, copy or
import it into your own folder rather than editing theirs.

Never commit credentials (`SECRETS.yaml`, API keys, endpoint tokens) or large downloaded datasets.
