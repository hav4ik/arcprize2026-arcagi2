# Research notes, 2026-09-30

## NVARC (ARC Prize 2025, 1st place): https://github.com/1ytic/NVARC (paper `nvarc_2025.pdf`)

**Scores**
- 27.64% public LB during the competition. A post-deadline 4B variant scored 29.72%; a 2B model scored 22.22% in 6h.
- The paper gives no private score.

**Kaggle pipeline**
- Budget: 4×L4 GPUs, 12h for 240 tasks.
- Per-puzzle test-time training: LoRA reset for each puzzle (r=256, α=32, rsLoRA, LR 5e-5), trained 1 epoch on 128 augmented copies (8 rotations/flips × 16 colour permutations). Loss is computed on output grids only.
- Decoding: 16 augmented views per test input, decoded with a batched depth-first search that keeps completions with cumulative probability ≥ 20%.
- Selection: each candidate is re-scored under the same 8 augmentations, then ranked by (how often the search found it − mean NLL across augmentations).

**Base model**
- Qwen3-4B-Thinking-2507, vocabulary cut to 16 tokens (digits, newline, chat tokens).
- Full fine-tune on 3.26M samples: NeMo-RL/Megatron, 4×8 H100, 27h, LR 1e-4, global batch 256, 1 epoch.

**Synthetic data generation (`SDG/`)**
- Seeds: human descriptions from H-ARC plus BARC seeds, giving 3,268 puzzle summaries (Claude Opus/Sonnet + gpt-oss-120b, and 29 eval puzzles labelled by hand).
- gpt-oss-120b mixed pairs of summaries into 266k new ones, then wrote input-generator code (must pass unit tests) and output code (20 samples each).
- A majority-vote filter kept 103k puzzles.

**What mattered:** scaling the synthetic data, 4B over 2B, and the candidate-selection formula.
**What didn't:** BARC data, batch-invariant decoding (too slow), and TRM (+0 for 4B; the best submission had no TRM).

**Ideas**
- Use vLLM/SGLang for decoding to fit more views and samples in the 12h.
- Mix 3+ concepts per synthetic puzzle.
- Filter synthetic data by difficulty using the model itself.
- Add loss on input grids during per-puzzle training.
- A 2B model with more test-time compute.

**Gotchas**
- Set `PYTHONHASHSEED`: the scoring augmentations depend on `hash()`.
- Unsloth and flash-attn versions are pinned, plus a hand patch to Unsloth.
- `run_sft_4b.sh` points at a config path that doesn't exist; the file is at `ARChitects/sft_mg.yaml`.

## Program-based generators (ranked)

1. **ARC-GEN** (`google/ARC-GEN`, Apache-2.0)
   - 900 generators, each validated against its real task.
   - Covers 891 of 1000 ARC-AGI-2 training tasks and 0 of 120 eval tasks (checked against our data).
   - Run with `python3 arc_gen.py generate <id> N`.
2. **NVARC synthetic data and pipeline**: the only source that combines two concepts per puzzle.
3. **RE-ARC** (`michaelhodel/re-arc`, MIT): 400 ARC-1 generators plus verifiers, with difficulty settings.
4. **ARC-TGI** (`Omega-Reasoning/ARC-Task-Generators-Inventory`, Apache-2.0)
   - 461 generators: 55 for ARC-AGI-2 training tasks and 11 for eval tasks (exclude those 11).
   - Comes with natural-language reasoning chains.
5. **BARC** (`xu3kev/BARC`): LLM-remixed seeds, ARC-1 flavour, licence unclear.
6. **simon-arc** (neoneye): primitive-skill curriculum. **arc-dsl** (Hodel): a library for writing new generators.

**Gaps no generator covers well (where our own generators would add the most)**
- Legends inside the grid that define what a colour or shape means.
- Rules that change depending on a marker, region or object property.
- Three or more interacting rules.
- Large, cluttered 25–30-wide grids.
- Non-local operations: counting or ordering objects, paths around obstacles, output size determined by content.
- Checks that the example pairs uniquely determine the rule.

## DeepSeek V4 on ARC-AGI-2

**Scores:** ARC Prize Verified, Semi-Private, presumably pass@2. DeepSeek publishes no ARC numbers itself.

| Model | Max | High | Low | None | $/task (Max) |
|---|---|---|---|---|---|
| V4 Flash 0731 | 61.4% | 56.0% | 46.0% | 2.1% | $0.04 |
| V4 Pro 0813 | 61.3% | 59.7% | 56.2% | 0.8% | $0.60 |

- Frontier models score about 90–95% (GPT-6 Astra, Claude Opus 5.5, Gemini 3.8 Flash).
- V3.2 scored 4%.

**Prompt:** ARC Prize's plain harness, copied to `notes/prompts/` from `arcprize/arc-agi-benchmarking`.
- **Prompt text:** `arcprize_official_system_prompt.txt`, sent as a single **user** message.
- **Grid format** (`prompt_manager.py`): `json.dumps` grids inside `--Example {i}-- \n\n INPUT: \n\n...OUTPUT: \n\n...`.
- **Parsing:** a `\boxed{}` regex, else the last balanced list of lists; exact match. pass@2 = two independent calls per test input, with no feedback between them.
- **Settings ARC Prize used for V4 are unpublished** (provider, max_tokens, temperature). Best guide: their V3.2 run used `max_tokens=100000`, `reasoning_effort=high` (`dsv32_sample.json`).
  - DeepSeek recommends temperature 1.0, top_p 1.0, and up to 384K output tokens for high/max.
- **Reasoning effort** is a text prefix added in thinking mode (`deepseek_v4_0813_reasoning_effort_prefixes.txt`, `deepseek_encoding_dsv4.py`). With the API, pass `reasoning_effort="max"`.
- **Speculation, unverified:** gains came from training on ARC-like synthetic environments. Takeaway: a strong reasoning model with a plain prompt and no harness reaches about 61%.
