# E072 backlog: ranked harness experiments (the pods never idle; the queue runner takes the next job)

Common rules
- **Workload:** `eval120_kaggle` (120 Kaggle-version eval originals, 2 attempts, rerun mode, about 5 h at V12 speed). Halves:
  `workloads/eval120_kaggle_{dev,holdout}_ids.txt` (60/60, seeded, stratified by V12 replica difficulty).
- **Incumbent:** Manh V12 as submitted, notebook `kaggle/dsv41_tools/out/manh_v12_363638159` (sha256 c47be5a8), model E128 (Kaggle
  `chankhavu/dsv41-flash-1017-arc-tool-e128-2bit` v1), vllm-wheels v11, arc2-2026-src v23. Variants are env overrides in the job file;
  `bin/mk_variant_nb.py` patches only the `_MT_EXPECT` entry of cell 0b that the override changes (without that, cell 0b fails in a rerun
  and falls to the v3 fallback = R10 crash path). Code changes need a new notebook (new sha in the job).
- **Promote only on a paired win:** `paired.py ARM BASE...` (per-task pass@2 on the same tasks, task bootstrap): the overall 95% CI
  excludes 0 AND the holdout half (or a second run of the arm) agrees (same sign, point estimate >= half the overall one). A single arm
  run is a candidate, not a result. Judge size against the noise baseline: the SD of replicate-vs-replicate paired differences (1).
- Compare arms on the same pod where possible (pod speed differs: calibration job (7)). Record host RAM/VRAM alerts (`samp.alerts`).
