Notes

  • Counts use consumed inputs only (each rollout minus its final token), once per position, 48 lookups per token over both layers. Token sequences were rebuilt with the model's encoding.py and match the API's per-turn prompt token counts on all 78,992 turns.
  • Hit rate is a selection diagnostic, not a quality result. Each candidate mask is checked next by teacher-forced NLL on the eval traces and by full ARC eval runs on the self-hosted model.
  • Kaggle 4×L4 host RAM leaves about 122 GiB for the pinned table plus a 2.9 GiB original-to-compact map.
