2. Why Each Experiment Worked (or Didn't)

Qwen3.8-27B (TPUv7 in FP8)

  • Exp 1 (No Tools, 19.8%): Without tools, Qwen thinks for 45k+ tokens on hard tasks and got cut off at the 48k cap in 62% of attempts before outputting a grid.
  • Exp 2 (Python REPL, 37.1% — +17.3% jump): Capping each thinking turn at 8k tokens and forcing code execution stopped the cutoffs. 52% of puzzles got a solve() program that passed all training pairs.
  • Exp 3 (Best-of-8, 54.1% Kaggle / 55.8% ARC Prize — +17.0% jump): Running 8 attempts with a 96k cap lifted training-pass coverage from 52% to 70%, and majority voting filtered out overfitted programs (wrong programs disagree on the test grid; right ones agree).
  • Exp 4 (Image + Tools, 35.3% Kaggle / 38.3% ARC Prize): Passing the RGB task image solved 19 new puzzles that Text-only missed, lifting ARC Prize pass@2 to 38.3%, but lowered pass@1 because seeing the image made Qwen visually guess offsets on Turn 1.
  • Exp 5 (1 Text + 1 Image + Audit, 33.3% / 36.5%): Gave our highest N=2 pass@1 (33.3%), but pass@2 stayed flat (see Section 3).
  • Exp 6 (Upgraded Tools, 36.0% Kaggle / 38.4% ARC Prize): Cross-pair solve() sharing cut wrong-size grids from 30% to 21% and gave our highest N=2 ARC Prize pass@2 (38.4%), though letting the 1-turn audit overwrite attempt_1 hurt pass@1.

Gemma-4 (AI Studio API)

  • Run 1 (MoE 26B, 1.8%) vs. Run 3 (Dense 31B, 8.4%): With only 4B active parameters per token, the MoE model loses track of 2D grid coordinates and fails size checks 28% of the time.
  • Run 4 (196k Cap, 10.8%): Raising Gemma-4's token cap from 32k to 196k did not make it think longer—Gemma naturally stops thinking around 11k–13k tokens.
  • Run 5 (Python REPL, 21.6% — +10.8% jump): Just like Qwen, giving Gemma-4 a Python REPL with automatic training-pair verification doubled its score.
  • Run 6 (Prompt Tricks, 16.2% — −5.4% drop): Adding pre-computed perception summaries and cell-level diffs caused Gemma to over-patch its code to fit the training pairs, dropping test precision from 58% to 45%.
  • Run 8 (Multimodal Image + scipy + 3 Attempts, 27.2% Kaggle / 28.7% ARC Prize): Adding the RGB puzzle image, pre-loading scipy, and ranking 3 attempts boosted Gemma-4 by +10.2% on pass@1 and +5.6% on pass@2.

3. Failure Analysis

3.1 Three Main Reasons Models Fail

  1. Overfitting the Training Pairs (~40% of programs that pass training fail on the test grid): Because puzzles only have 2–4 training examples, models often write a rule that passes training by accident—such as hardcoding a color integer or direction that happened to be constant in training.
  2. 1-to-4 Pixel Near Misses (10%–18% of all attempts get the exact right size and ≥95% of cells right): Both models frequently find the right conceptual rule, but miss by 1–4 pixels due to an off-by-one bounding-box index (r1 vs r1+1) or color overlap order.
  3. Wrong Output Size on Size-Changing Puzzles (21%–30% of attempts): When the output grid changes dimensions and solve() fails the training check, the fallback prediction has the wrong shape.

3.2 How Failures Compare Between Gemma-4 and Qwen3.8

  • Same hard puzzles: Both models fail most on large grids (>600 cells, up to 30×30) and 2-example puzzles. 92% of puzzles solved by Gemma-4 are a subset of the 101/167 puzzles solved by Qwen3.8.
  • Why Qwen is 15–27 points higher: Gemma-4 stops thinking at ~11k tokens and writes a full solve() guess on Turn 1 without inspecting the arrays first. Qwen3.8 uses 12–15 REPL turns to inspect objects and keeps improving up to 70k+ tokens.
3.3 Why Combining Image + Tools in Exp 5 (N=2) Didn't Jump to 48.5%:

Pooling the 2 attempts of Exp 2 (Text) with the 2 attempts of Exp 4 (Image) solves 48.5% (81/167) of the benchmark (22 solved only by Text, 19 only by Image). Yet Exp 5 (1 Text + 1 Image) got 36.5%. Why?

  1. Losing the 2nd retry inside each modality: A single tool attempt is noisy (Attempt 2 adds +5% in Text and +8% in Image). Cutting Text from 2 attempts to 1 attempt lost ~5% within-modality accuracy, cancelling out the cross-modality gain.
  2. Image attempts overfit training more often: In Exp 5, Text programs that passed training were right on test 66% of the time, vs. 58% for Image programs (Attempt 1 Text scored 31.0% vs 23.8% for Attempt 2 Image).
  3. No tie-breaker with only 2 attempts: On 11 puzzles in Exp 5, both the Text and Image attempts passed 100% of training pairs with different test grids (one right, one overfitted). With only 1 attempt each, there is no majority vote to break the 1-vs-1 tie.

4. Best Next Steps (Future Hypotheses)

  1. Adaptive 2-Wave 3 Text + 1 Image Ensemble (+10% to +13% expected pass@2, fits Kaggle in ~7.8h): Run 2 Text+Tools attempts first. If both pass training and agree on the test grid (~45% of puzzles, >85% accurate), stop immediately. Only when they fail or disagree, run 1 more Text attempt + 1 Image attempt and majority-vote across all 4.
  2. Keep Original train_passed Grid Locked During Post-Submit Audit (+4% pass@1, 0 extra tokens): Never let the 1-turn audit overwrite attempt_1; keep the first training-passing grid as attempt_1 and store any post-audit revision as attempt_2.
  3. Rotation & Color-Swap Check Inside submit_program (+3% to +5%): Automatically test if solve(rot90(x)) == rot90(y) on the training pairs. Programs that pass cannot have hardcoded coordinates and get ranked above overfitted programs.
  4. 1-Turn Pixel Tie-Breaker for Near Misses (+2% to +4%): When two training-passing attempts output the same shape but differ on ≤5 pixels, run 1 short turn asking the model to inspect those exact (row, col) cells.
